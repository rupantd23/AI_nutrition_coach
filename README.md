# Rasoi Saathi
render link:https://ai-nutrition-coach-okp3.onrender.com/
**Hungry, but your fridge and your brain are both saying “nothing”?** Snap a dish, tell Rasoi Saathi what’s in your kitchen, or pick the taste you’re craving. It turns that little nudge—spicy, tangy, crunchy, comforting—into Indian recipe ideas you can actually cook, complete with ingredients, steps, time, and estimated nutrition.

Think of it as a friend in the kitchen: one who can look at your food photo, help you decide what sounds good, and read the recipe while you cook.

## What it does

- **“What’s that dish—and what else could I make?”** Snap or upload a JPG, PNG, or WebP food photo. The app identifies what it can see and spins that into recipe ideas.
- **“Here’s what’s in my fridge.”** Type your ingredients and find recipes to make with them, plus a clear list of anything extra you’ll need.
- **“I’m hungry, surprise me.”** With nothing picked for ingredients, choose a mood—sweet or spicy, crispy or creamy—along with meal, cuisine, and time. Get ideas that fit the craving.
- **Dietary preferences:** Optionally filter for vegetarian, vegan, gluten-free, dairy-free, nut-free, low-calorie, or higher-protein recipes; add custom restrictions or a calorie target.
- **Voice:** Dictate ingredients in English or a supported Indian language, or use auto-detect. Choose English, Hindi, Bengali, Gujarati, Kannada, Marathi, Punjabi, Tamil, or Telugu to hear a recipe translated and read aloud; pause or resume playback anytime.
- **Recipe details:** See ingredient quantities, cooking steps, servings, rough prep/cook times, and estimated per-serving nutrition.

Nutrition values are estimates generated by the model, not calculations from a verified nutrition database. Check labels and cross-contamination risks for allergies. This app is not medical advice.

## Sarvam APIs

| Feature | Sarvam API / model | How the app uses it |
| --- | --- | --- |
| Photo understanding | Chat Completions V2, `gemma4` | Analyzes the uploaded image and summarizes the visible dish and likely ingredients. |
| Recipe generation | Chat Completions, `sarvam-105b` | Generates recipes in a structured JSON format from the photo analysis, ingredients, or discovery preferences. |
| Dictation | Speech-to-Text, `saaras:v4` | Transcribes audio in the selected language or auto-detects it. |
| Recipe translation | Text Translation, `mayura:v1` | Translates a recipe into the selected read-aloud language. |
| Read aloud | Text-to-Speech, `bulbul:v4-flash` | Reads the translated recipe in a compatible language-specific voice. |

## Run locally

### Requirements

- Python 3.10 or newer
- A Sarvam API key with available credits

### Setup

From this project folder, create and activate a virtual environment, then install the dependencies:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Create a `.env` file in the project folder containing your key:

```env
SARVAM_API_KEY=your_sarvam_api_key
```

Start the app:

```bash
python app.py
```

Open [http://127.0.0.1:5000](http://127.0.0.1:5000) in your browser. Stop the server with **Ctrl+C**.

The `.env` file is ignored by Git. Never commit or share your API key.
